# Relapse Detailed Demo Narration

## Duration
Approximately 5 minutes

## Script

### [0:00-0:20]
**Voice-over:**
From the care recipient perspective, the watch is always present: simple, glanceable, and ready when guidance is needed. Relapse connects that care recipient experience with caregiver support on phone.

**On screen (side by side):**
Watch: Launch screen transitioning to Pairing screen.
Phone: App launch -> splash -> auth entry point.

### [0:20-0:50]
**Voice-over:**
Before the care recipient can be monitored, the watch waits in pairing mode and shows a code. The caregiver completes onboarding so the care recipient device can be linked securely.

**On screen (side by side):**
Watch: Pairing screen idle state with pairing code visible.
Phone: Sign Up screen (name, email, password, terms) -> submit -> Login success.

### [0:50-1:25]
**Voice-over:**
Pairing starts from the care recipient watch code. Once the caregiver enters that code, the care recipient experience shifts from waiting to active monitoring.

**On screen (side by side):**
Watch: Pairing code displayed -> status changes from waiting to paired.
Phone: Home -> Add Patient -> enter pairing code -> confirm.

### [1:25-1:55]
**Voice-over:**
After pairing, the care recipient watch lands on a clean monitoring view. Caregiver profile setup now powers the labels, reminders, and context the care recipient will receive.

**On screen (side by side):**
Watch: Monitoring screen appears with sync status.
Phone: Patient Setup form (name, age, notes, optional photo) -> save.

### [1:55-2:25]
**Voice-over:**
The care recipient watch now reflects Safe Zone state in real time. The caregiver defines that zone on phone by placing a center point and radius.

**On screen (side by side):**
Watch: Monitoring screen safe-zone indicator reflecting current status.
Phone: Safe Zone map pin placement -> radius adjustment -> save configuration.

### [2:25-3:05]
**Voice-over:**
Memory reminders are designed for the care recipient moment: familiar prompts delivered on-watch at the right place and time. The caregiver prepares those moments on phone with text, media, and location rules.

**On screen (side by side):**
Watch: Monitoring screen remains active with reminder queue/status visible.
Phone: Memory list -> Create Reminder -> fill fields -> attach photo/audio/video -> set map trigger -> save.

### [3:05-3:30]
**Voice-over:**
When a reminder trigger fires, the care recipient feels a watch vibration first, then sees reminder title, message, and available media cues. The caregiver phone mirrors that event in the activity feed for awareness.

**On screen (side by side):**
Watch: Monitoring -> vibration/haptic cue -> Reminder alert screen opens with title/body and media cue -> dismiss action.
Phone: Activity/event feed shows reminder-trigger event entry.

### [3:30-3:55]
**Voice-over:**
Between alerts, the care recipient continues with a calm monitoring screen on watch. In parallel, the caregiver can review movement summaries and recent events in Activity.

**On screen (side by side):**
Watch: Monitoring dashboard with latest sync time and connection state.
Phone: Activity screen with current location card, summary tiles, movement chart, and event feed.

### [3:55-4:20]
**Voice-over:**
Safe Zone transitions are visible on the care recipient watch and caregiver phone in both directions. On exit, the watch gives a vibration alert, shows an out-of-zone state, and can launch guided navigation back toward safety, while the phone raises an alert. On entry, both sides return to in-zone status.

**On screen (side by side):**
Watch: Monitoring status changes to out-of-zone -> vibration/haptic alert -> pre-navigation warning/countdown appears -> navigation screen with direction arrow and distance -> return to monitoring with in-zone status.
Phone: Safe-zone status transitions Inside -> Outside with alert moment, then Outside -> Inside recovery state.

### [4:20-4:40]
**Voice-over:**
If care needs change, the care recipient watch remains simple while caregiver settings are adjusted on phone, then synced back to the watch experience.

**On screen (side by side):**
Watch: Settings access shown briefly, then return to monitoring.
Phone: Settings -> Edit patient profile -> Edit caregiver profile.

### [4:40-5:00]
**Voice-over:**
Relapse keeps the care recipient experience clear on-watch while keeping caregivers informed on-phone, so both sides stay connected and ready to act.

**On screen (side by side):**
Phone and watch closing montage -> branded end frame and logo.
